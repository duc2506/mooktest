# MookTestFrontend

Angular 20 SPA cho Trainer và Trainee. Xem [hướng dẫn toàn bộ dự án](../../README.md).

- npm ci: cài dependencies.
- npm start: http://localhost:4200, proxy /api sang http://localhost:5243.
- npm run build: xuất dist/MookTestFrontend/browser.
- npm test -- --watch=false --browsers=ChromeHeadless: kiểm thử.

Đăng ký chỉ tạo Trainee. Tạo Trainer bằng scripts/create-trainer.ps1 tại thư mục gốc.
